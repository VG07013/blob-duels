# Third-Party Asset Record

## Current status

The environment-art pass uses the CC0 model packs listed below. The source license
files are preserved beside each pack under `assets/environment/models/kenney/`.
All project audio remains original procedural audio.

## Original environment textures

The seamless SVG textures in `assets/environment/textures/` were authored for Blob
Duels. They cover wood grain, painted panels, stone blocks, brushed metal, roof
shingles, fabric weave, soil pebbles, and toy plastic. They do not contain external
images or extracted content.

## Audio

All WAV files in `assets/audio/` are original procedural audio generated locally by
`assets/audio/generate_audio.py`. The generator uses only Python standard-library
math, deterministic pseudo-random noise, oscillators, envelopes, filtering, and WAV
encoding. It does not contain, download, resample, or transform any external audio.

The supplied arena screenshots were used only as broad style references for the game.
No audio or visual content was extracted from them.

## Original generated sound effects and ambience

The pack includes original UI, projectile, damage, blob impact, charge, fling, air
rush, launch-pad, wind, machinery, low-health, respawn, round, victory, defeat, and
ambient sounds. Every source WAV is generated by the same local script.

Legacy `.res` files in `assets/audio/` are Godot resource versions of earlier original
procedural WAVs. They are retained only for compatibility and contain no third-party
content.

## Reproduction

From the project root:

```bash
python3 assets/audio/generate_audio.py
```

Opening the project in Godot 4 imports or refreshes the generated WAV resources.
